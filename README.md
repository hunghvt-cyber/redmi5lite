# Dai Ca Minimal

Custom watchface for **Redmi Watch 5 Lite only**, 410 × 502 pixels.

Black background, large white 24-hour time, Vietnamese weekday and DD/MM date.

GitHub Actions builds on Windows. Download the `DaiCaMinimal-Redmi5Lite` artifact after a successful run, extract it, then install `DaiCaMinimal.bin` using an already paired Gadgetbridge on Android.

A successful compiler run is not a physical-watch test. This project does not replace firmware.

Tools: [EasyFace](https://github.com/m0tral/EasyFace), [Gadgetbridge](https://gadgetbridge.org/).
